# English technical documentation

This directory contains complete topic references rather than a condensed
translation of the Portuguese manuals.

- [AllValidations](AllValidations.md): direct boolean and typed Result APIs.
- [BrData](BrData.md): strict date/time formatting, parsing, and validation.
- [BrFormatter](BrFormatter.md): CPF, CNPJ, CEP, phone, currency, and KM.
- [BrZod](BrZod.md): fluent rules, locales, policies, and map validation.
- [Alphanumeric CNPJ](CnpjAlfanumerico.md): validation, formatting, and test
  generation for the 2026 format.
- [Extensions](Extensions.md): null-safe bool, string, and list helpers.
- [Contracts and notifications](Contract.md): accumulating validation and
  `ValidationResult` integration.
- [Migration](migration.md): focused entry points and aggregator compatibility.

The Portuguese source set remains available under [`../pt-BR`](../pt-BR).
