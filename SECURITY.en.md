# Security policy

## Responsible disclosure

Do not publish vulnerabilities, credentials, or personal documents in issues.
Use the private channel listed by the repository maintainer and include
version, platform, impact, and a minimal reproduction. The remote repository
and a valid private channel must exist before publishing to pub.dev.

## Test data

Use only public vectors, synthetic numbers, or values explicitly reserved for
testing. Do not send a real CPF, CNPJ, CNS, phone number, address, PIX key, or
other document in an issue, pull request, log, screenshot, or fixture.

## Limits

The package validates formats and check digits locally. It does not query
official databases and does not prove identity, existence, registration
status, ownership, or authorization. Consumers must apply appropriate access
control, data minimization, and legal requirements.
